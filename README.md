# ImproWE
An online task and habbit tracker.

# Fuctionality
Create custom plan:
  Schedule:
  - Name
  - Description
  - Expected execution time
  - Day condition
  - Tags
  
  Task:
  - Name
  - Description
  - Tags
  - Due date

  Tag:
  - Name
  - Icon
  - Color

Reorganise:
Tool for Task planning around scheduled activities

Display:
Dashboard with all statistics and the plan itself.
View modes:
- Daily
- Weekly
- Monthly
- Yearly (Simplified)
